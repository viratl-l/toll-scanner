# Toll Scanner — รวมค่าทางด่วน

เว็บแอปภาษาไทย ฟรี ไม่มีบัญชี ไม่มี API key อ่านภาพด้วย [Tesseract.js](https://github.com/naptha/tesseract.js) (Apache-2.0) ในเบราว์เซอร์ รองรับมือถือและคอมพิวเตอร์

## เปิดใช้

เมื่อเปิด GitHub Pages แล้ว: https://viratl-l.github.io/toll-scanner/

1. เลือกหลายภาพ (JPEG/PNG แนะนำ ภาพละหนึ่งใบ ขนาดไม่เกิน 25 MB) หรือกดถ่ายภาพ
2. หรือเปิดกล้องอัตโนมัติ อนุญาตกล้อง วางใบเสร็จให้ตรงและถือให้นิ่งประมาณ 2 วินาที ระบบจะอ่านภาพ เว้นประมาณ 8 วินาทีก่อนจับภาพต่อไป เปลี่ยนใบเสร็จหลังสแกน ปิดกล้องเมื่อเสร็จ
3. ตรวจยอดเงิน วันที่ ด่าน และเลขใบเสร็จ แก้ไขช่องที่อ่านผิด กด **ยืนยัน** เพื่อรวมยอด การแก้ไขจะยกเลิกการยืนยันเดิม
4. ภาพไฟล์เดิมถูกข้ามด้วย SHA-256; เลขใบเสร็จ + วันที่ + ด่านตรงกันจะเตือนซ้ำและไม่รวมยอด เลือกเก็บรายการซ้ำและยืนยันได้หากเป็นคนละใบ อย่าใช้ยอดเงินเท่ากันเป็นหลักฐานว่าซ้ำ
5. เพิ่มเองหากอ่านไม่สำเร็จ ลบรายการที่ไม่ต้องการ แล้วดาวน์โหลด CSV (UTF-8 BOM เปิดใน Excel ได้) เฉพาะรายการยืนยันและไม่ถูกกันซ้ำ
6. ปิด/โหลดหน้าใหม่ข้อมูลจะหาย ให้ดาวน์โหลด CSV ก่อน

ติดตั้ง: Android/คอมพิวเตอร์ใช้เมนูเบราว์เซอร์ → ติดตั้งแอป (หากรองรับ); iPhone Safari → แชร์ → เพิ่มไปยังหน้าจอโฮม

## ความเป็นส่วนตัว

- ไม่มีการส่งภาพหรือข้อความ OCR ไปยังเซิร์ฟเวอร์ ไม่มี analytics และไม่มีการเก็บภาพใน localStorage, IndexedDB หรือ Cache Storage ของแอป ภาพใช้ชั่วคราวในหน่วยความจำและส่งให้ OCR worker ภายในเครื่อง
- ข้อมูลรายการและข้อความ OCR อยู่ในหน่วยความจำแท็บเท่านั้น CSV คือไฟล์ที่ผู้ใช้เลือกดาวน์โหลด
- ครั้งแรกที่ OCR ทำงานต้องดาวน์โหลด Tesseract.js 5.1.1, worker, WebAssembly core และโมเดล tha/eng ผ่าน CDN (jsDelivr และแหล่งโมเดลเริ่มต้นของ Tesseract.js) ผู้ให้บริการเห็น IP/ข้อมูลการเชื่อมต่อ แต่แอปไม่ส่งภาพให้
- Tesseract.js อาจเก็บโมเดลภาษาใน IndexedDB ซึ่งเป็นซอฟต์แวร์/โมเดล ไม่ใช่ใบเสร็จ Service worker เก็บเฉพาะไฟล์เปลือกแอปในรายการอนุญาต

## ข้อจำกัดของต้นแบบ

- **หลายภาพ**: อ่านทีละไฟล์ตามลำดับ **หลายใบในภาพเดียว**: ยังไม่มี segmentation อ่านทั้งภาพเป็นรายการเดียว อาจได้ยอดผิด/กำกวม ต้องครอปแยกเองก่อน หรือเพิ่มรายการเอง
- กล้องอัตโนมัติใช้ความเปลี่ยนแปลงของภาพขนาดย่อ ไม่ได้ตรวจจับขอบใบเสร็จ ไม่รับประกันความคมหรือว่ามีใบเสร็จอยู่ อาจสแกนซ้ำเมื่อถือใบเดิม; ภาพกล้องใหม่มี hash ต่างกันได้
- OCR และตัวแยกยอดเป็น heuristic ไม่ใช่ระบบบัญชีที่รับรองความถูกต้อง รูปซีด แสงสะท้อน ตัวอักษรเล็ก/เอียง และข้อความยอดหลายค่าทำให้อ่านผิดได้ ทุกผลต้องตรวจและยืนยันเอง ไม่มีการแปลงปีหรือวันที่อัตโนมัติ
- **ออฟไลน์**: หลังเปิดออนไลน์และ service worker ติดตั้งสำเร็จ หน้าแอป การเพิ่มเอง รวมยอด และ CSV ใช้ได้ออฟไลน์ OCR ออฟไลน์ยังไม่รับประกัน เพราะ worker/core/CDN อาจไม่อยู่ในแคช แม้โมเดลเคยโหลดแล้ว ไม่ควรคาดหวัง OCR ออฟไลน์ในรุ่นนี้
- Safari/HEIC และมือถือบางรุ่นอาจอ่านภาพหรือใช้กล้องไม่ได้ ให้แปลง JPEG/PNG และใช้ HTTPS รองรับเบราว์เซอร์สมัยใหม่ที่มี WebAssembly, createImageBitmap และ Web Crypto

## เผยแพร่ GitHub Pages ฟรี

ไม่มี build step หรือ dependency ที่ต้องติดตั้ง

1. ตรวจว่าไฟล์ index.html, app.js, core.js, style.css, sw.js, manifest.webmanifest และ icon.svg อยู่ root ของ branch main
2. ไปที่ Repository → Settings → Pages
3. Source → **Deploy from a branch** → Branch **main** → **/(root)** → Save
4. รอ Actions ชื่อ pages build and deployment สำเร็จ แล้วเปิดลิงก์เว็บไซต์ข้างต้น
5. ทดสอบบนมือถือ อนุญาตกล้อง ตรวจยอด แก้ไข และดาวน์โหลด CSV

อ้างอิง [เอกสาร GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site) — public repository ใช้ GitHub Free ได้

อัปเดตโดย commit ไฟล์ลง main แล้วรอ Pages สำเร็จ เพิ่มเลข CACHE ใน sw.js เมื่อเปลี่ยนเปลือกแอป ปิดทุกหน้าต่างแอปแล้วเปิดใหม่เพื่อให้ worker รุ่นใหม่ทำงาน

## พัฒนาและทดสอบ

Node.js 18 ขึ้นไป: `npm test` (ไม่ต้อง npm install) รัน static HTTP server ที่ root เช่น `python -m http.server 8080` แล้วเปิด localhost:8080; อย่าเปิด file:// เพราะ module และ service worker ต้องใช้ HTTP/HTTPS

Automated tests ครอบคลุมเลขไทย/สตางค์ การกันวันที่และ VAT ออกจากยอด ความกำกวม การตรวจซ้ำ การรวมเฉพาะรายการยืนยัน และการ escape CSV ป้องกัน formula injection

ตรวจด้วยมือก่อนใช้งานจริง: หลายภาพ, ภาพเดิมสองครั้ง, คนละใบยอดเท่ากัน, กล้องไม่ได้รับอนุญาต, ภาพอ่านไม่ได้, แก้ยอดหลังยืนยัน, ลบ, CSV ภาษาไทย และออฟไลน์เพิ่มเอง ไม่มีชุดใบเสร็จจริงเพื่อวัดความแม่นยำ OCR และยังไม่ได้รับรองการใช้งานกล้องบนอุปกรณ์ทุกชนิด

## ภาพหมุนและหลายใบในภาพ (รุ่น 2)
เมื่อเลือกภาพหรือถ่ายภาพ แอปเปิดหน้าจัดภาพ กดหมุนซ้าย/ขวาจนตัวหนังสือตั้งตรง ลากกรอบหรือกรอกตำแหน่งเป็นเปอร์เซ็นต์ให้ครอบหนึ่งใบ กดเพิ่มกรอบ ทำซ้ำครบทุกใบ แล้วกดอ่านกรอบที่เพิ่ม อ่านแต่ละกรอบแยกเป็นรายการ รองรับสูงสุด 20 กรอบต่อภาพ ข้ามภาพหรือ Escape เพื่อยกเลิก ภาพและกรอบยังอยู่เฉพาะหน่วยความจำ รุ่นนี้ยังไม่ทำ segmentation อัตโนมัติหรือแก้ perspective ส่วนกล้องอัตโนมัติอ่านภาพเต็มและควรใช้ครั้งละหนึ่งใบ
