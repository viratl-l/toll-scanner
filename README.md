# Toll Scanner — รวมค่าทางด่วน ง่าย ๆ

เปิดใช้: https://viratl-l.github.io/toll-scanner/

เว็บแอปภาษาไทย ใช้ฟรี ไม่ต้องสมัครบัญชี ไม่มี API key อ่านภาพด้วย [Tesseract.js 7.0.0](https://github.com/naptha/tesseract.js) (Apache-2.0) ในเครื่องผู้ใช้

## วิธีใช้ รุ่น 4

1. **เลือกรูปใบเสร็จ** (เลือกหลายรูปได้), **ถ่ายรูป**, หรือ **สแกน** จากกล้อง
2. ระบบหาทิศตัวหนังสือ ปรับภาพ อ่านเทียบหลายรอบ แล้ว **บวกยอดที่ตรวจได้อัตโนมัติ** ไม่ต้องกดยืนยันทีละใบ ยอดที่อ่านไม่ได้จะเว้นว่างและยังไม่รวม กรอกหรือแก้ตัวเลขในช่องยอดเงิน ระบบคำนวณใหม่อัตโนมัติ
3. **ดาวน์โหลด CSV** เมื่อตรวจตัวเลขเรียบร้อย เปิดใน Excel / Google Sheets ได้

ไม่มีรูปหรืออ่านไม่ได้: กด **เพิ่มยอดเอง** แล้วพิมพ์จำนวนเงิน วันที่ ด่าน และเลขใบเสร็จเป็นข้อมูลเสริมใน **รายละเอียดใบเสร็จ** ไม่บังคับกรอก ข้อมูลในหน้าเว็บอยู่ชั่วคราว ปิดหรือรีเฟรชจะหาย ให้ดาวน์โหลดก่อน

### ภาพเอียง หรือหลายใบในรูปเดียว

เปิดตัวเลือก **หมุนรูป / แยกหลายใบก่อนอ่าน** ก่อนเลือกรูป:

- ใบเดียว: กดหมุนซ้าย/ขวาให้ข้อความตั้งตรง แล้ว **สแกนและบวกยอด**
- หลายใบ: เลือก **หลายใบในรูป** ลากกรอบหนึ่งใบ หรือแตะสองมุมตรงข้าม → **เพิ่มใบนี้** ทำซ้ำจนครบ → **บวกยอด N ใบ** มีภาพเล็กให้ตรวจและเอาใบที่เลือกผิดออกได้
- ใช้คีย์บอร์ด: โฟกัสภาพในโหมดหลายใบ กดลูกศรเพื่อเริ่ม/เลื่อนกรอบ กด Shift + ลูกศรเพื่อปรับขนาด รองรับสูงสุด 20 ใบต่อรูป
- ปุ่ม × หรือ Escape ข้ามรูปนั้น ถ้าเลือกหลายรูปจะไปยังรูปถัดไป

รุ่น 4 ค้นหาตำแหน่งราคา/Price/Baht/Total และจับคู่กับตัวเลขในภาพอัตโนมัติ จึงอ่านหลายยอดจากภาพเดียวได้ในบางรูป โดยรวมยอด Total กับ VAT Included ของใบเดียวกันเพียงครั้งเดียว แต่ยังไม่มี segmentation ขอบใบเสร็จหรือการแก้ perspective ที่รับประกันผล อาจอ่านไม่ครบเมื่อซ้อนกัน เอียงมาก หรือข้อความเล็ก หากอ่านไม่ครบให้เปิดตัวเลือกแยกใบก่อน

### สแกนจากกล้อง

อนุญาตกล้องบน HTTPS ถือใบเสร็จหนึ่งใบให้ตัวหนังสือตั้งตรงและอยู่นิ่งประมาณ 2 วินาที ระบบถ่าย อ่าน และบวกยอด เว้นประมาณ 8 วินาทีก่อนภาพต่อไป เปลี่ยนใบเสร็จทุกครั้ง มีปุ่มถ่ายตอนนี้และปิดกล้อง

ฟังก์ชันนี้เป็นต้นแบบ ใช้ความเปลี่ยนแปลงของภาพ ไม่ได้ตรวจจับขอบหรือรับประกันความคม อาจสแกนซ้ำเมื่อถือใบเดิม ใช้ปุ่มถ่ายรูปหรือเลือกภาพหากกล้องไม่รองรับ

### ตรวจรายการซ้ำ

ข้ามรูปไฟล์เดิมด้วย SHA-256 และกันรายการเลขใบเสร็จ + วันที่ + ด่านตรงกันออกจากยอด (รายการแรกยังรวมอยู่) เลือก **เป็นคนละใบ ให้บวกยอดนี้ด้วย** เมื่อเตือนผิด การลบรายการแรกจะตรวจรายการที่เหลือใหม่ ไม่ใช้จำนวนเงินเท่ากันเป็นหลักฐานว่าซ้ำ ภาพถ่ายใหม่และ OCR ที่ผิดอาจทำให้ตรวจซ้ำไม่พบ

## ความเป็นส่วนตัวและข้อจำกัด

- ภาพ ข้อความ OCR และรายการอยู่ในหน่วยความจำเท่านั้น ไม่อัปโหลด ไม่เก็บใน localStorage/IndexedDB/Cache Storage ของแอป ไม่มี analytics ภาพตัวอย่างในหน้าจัดรูปถูกล้างเมื่อปิดหน้านั้น
- ครั้งแรกต้องโหลดซอฟต์แวร์ OCR, worker, WebAssembly และภาษา tha/eng จาก CDN (jsDelivr และแหล่งโมเดลเริ่มต้นของ Tesseract.js) ผู้ให้บริการเห็นข้อมูลการเชื่อมต่อ แต่แอปไม่ส่งภาพให้
- Tesseract.js อาจเก็บโมเดลภาษาใน IndexedDB ซึ่งเป็นโมเดล ไม่ใช่ใบเสร็จ Service worker เก็บเฉพาะไฟล์แอปที่ระบุไว้
- OCR และตัวแยกยอดอาจอ่านผิด โดยเฉพาะกระดาษซีด แสงสะท้อน ภาพเอียง หรือหลายยอดในกรอบเดียว ยอดที่อ่านไม่มั่นใจหรืออ่านขัดกันจะเว้นให้กรอกและไม่รวมอัตโนมัติ ยอดรวมเป็นผลจากตัวเลขที่ผ่านเงื่อนไขตรวจเทียบ ไม่ใช่การรับรองความถูกต้อง ต้องตรวจและแก้ก่อนใช้ ไม่มีการแปลงวันที่/ปีอัตโนมัติ
- แนะนำ JPEG/PNG ไม่เกิน 25 MB และ 50 ล้านพิกเซลต่อรูป HEIC/Safari หรือมือถือบางรุ่นอาจไม่รองรับ
- หลังเปิดออนไลน์และติดตั้ง service worker สำเร็จ หน้าแอป เพิ่มยอดเอง และ CSV ใช้ออฟไลน์ได้ แต่ **OCR ออฟไลน์ยังไม่รับประกัน** เพราะ worker/core/CDN อาจไม่มีในแคช

ติดตั้ง: Android/คอมพิวเตอร์ใช้เมนูเบราว์เซอร์ → ติดตั้งแอป (หากรองรับ); iPhone Safari → แชร์ → เพิ่มไปยังหน้าจอโฮม

## เผยแพร่ GitHub Pages ฟรี

ไม่มี build step หรือ dependency ที่ต้องติดตั้ง

1. ให้ไฟล์เว็บทั้งหมดรวมถึง prepare.js, ocr.js, ocr-core.js และ .nojekyll อยู่ root ของ main
2. Repository → Settings → Pages → **Deploy from a branch** → **main** → **/(root)** → Save
3. รอ Actions **pages build and deployment** สำเร็จ เปิดลิงก์ด้านบน

อ้างอิง [เอกสาร GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

อัปเดตโดย commit ลง main และรอ Pages สำเร็จ เพิ่มเลข CACHE ใน sw.js เมื่อเปลี่ยนเปลือกแอป ไม่รีโหลดแท็บที่มีรายการอยู่โดยอัตโนมัติ เพราะข้อมูลชั่วคราวจะหาย ปิดแล้วเปิดใหม่หลังดาวน์โหลด CSV หากต้องการโหลดรุ่นใหม่

## พัฒนาและทดสอบ

Node.js 18+: `npm test` ไม่ต้อง npm install ใช้ static HTTP server เช่น `python -m http.server 8080` แล้วเปิด localhost:8080 แทน file://

Automated tests ครอบคลุมเลขไทย/สตางค์ ตัวแยกยอด EXAT/คูปอง/ข้อความ OCR ที่มี noise ความกำกวม การกันซ้ำ และ CSV ป้องกัน formula injection

ตรวจ UI: เพิ่มยอดเอง/แก้ยอดรวมทันที, ลบแล้วคำนวณใหม่, CSV, เลือกภาพแล้วอ่านตรง, หน้าหมุนและหลายใบ, ภาพซ้ำ, กล้องถูกปฏิเสธ และหน้าจอมือถือ ยังไม่รับรองความแม่นยำ OCR บนใบเสร็จหรืออุปกรณ์ทุกชนิด
